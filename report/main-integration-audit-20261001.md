## Corrected integration gaps

1. **Model identity at study completion.** A final response with valid content but no returned model ID stopped the runner yet could pass completed-study analysis. The analyzer now applies the same identity/operational-error precedence as the shared runner. Wrong or missing identity rejects the completed-study claim.
2. **Transport failures versus backend drift.** A genuine transport failure's absent fingerprint could be treated as a backend change during analysis. It now remains a failed observation in the denominator when the recorded block is complete; an actual change in successful responses still stops/rejects the study.
3. **Archive run identity.** Exporting a run with a timestamped directory name changed its `raw_run` label after restoration. Archives now preserve the resolved original basename under a block namespace. Tests also cover equivalent `references/..` paths and reject unsafe member components.
4. **Reproducible development qualification.** The earlier strict development comparison depended on a local wrapper. A versioned policy, recorded capability baseline and tracked orchestration now use the shared provider/runner. Frozen enforcement remains unconditional; older settings hashes and readers retain compatibility.
5. **Current guidance.** README, AGENTS and planning now direct contributors to delivered candidate, review, rehearsal and analysis tools. Historical member handoffs retain their historical status and results.

The first three edge cases were reproduced before correction. These changes do not alter the shipped revision-3 prompts, solver constraints/objectives, validator semantics or historical scores. Source changes require new run identities. Raw records and prior archives are preserved.
